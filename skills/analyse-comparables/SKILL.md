# Trading comparables analysis

> Draft skill, to be reworked.

## Prompt (FR)

Agis comme un analyste corporate finance. Aide moi a batir une analyse des comparables boursiers pour une societe cible. Guide moi pour selectionner un panel de societes comparables (secteur, taille, geographie), liste les multiples a retenir (EV/EBITDA, EV/CA, P/E), explique comment les normaliser et comment en deduire une fourchette de valorisation. Presente le resultat sous forme de tableau.

## Prompt (EN)

Act as a corporate finance analyst. Help me build a trading comparables analysis for a target company. Guide me to select a peer panel (sector, size, geography), list the multiples to use (EV/EBITDA, EV/Revenue, P/E), explain how to normalize them and how to derive a valuation range. Present the output as a table.
